# Methods, licenses and limitations

## Data types

- **Research catalog**: primary URL, publisher, verified publication date when known, keywords and factual indexing description.
- **Dataset manifest**: upstream version and download URLs, NOT the actual data.
- **Discovery**: extracts links on declared official listing pages; it does not summarize or assess the validity of papers.
- **Agent Skills**: query this catalog, follow original sources and use dataset files only when explicitly obtained.

## Evidence boundaries

Observed AI usage ≠ theoretical task capability ≠ net time savings ≠ actual job displacement. Different providers use different sampling frames, users, products, time periods and taxonomies; compare methods before comparing numbers. O*NET task importance is not a direct time-allocation weight. Newly discovered records have `published_at: null` until verified.

OpenAI Signals: https://openai.com/signals/data-download/ (CC BY 4.0 for its dataset). Anthropic EconomicIndex: https://huggingface.co/datasets/Anthropic/EconomicIndex (dataset repository marked MIT). External occupational reference: https://www.onetcenter.org/database.html.

## Versioning

Scheduled updates append research records but do not delete or overwrite curated records. A research page changing or disappearing is not proof of retraction. Dataset links/revisions are tracked in JSON manifests. No full PDF or large raw dataset is mirrored by default; publisher copyright and datasets' licenses must be checked independently. Upstream website rendering may limit automated discovery; failure is surfaced, not quietly interpreted as an empty update.
